# kumpulanskill

A combined library of 216 agent skills for Claude, Codex, Cursor and other coding agents. 149 of them come with a runnable demo and 149 with example prompts (minimal, recreate, remix).

Most skills here are imported from [MengTo/Skills](https://github.com/MengTo/Skills) by Meng To, used under the MIT License (see [LICENSE](LICENSE)). The original README is kept as [UPSTREAM-README.md](UPSTREAM-README.md).

## How to use

- Each skill lives in `agent-skills/<category>/<skill-name>/SKILL.md`.
- Demos sit in `demo/index.html` next to the skill. Open the file in a browser; no build step.
- Example prompts are in `demo/PROMPT.md`.
- Browse every demo and prompt in [DEMOS.md](DEMOS.md), or the screenshots in [SCREENSHOTS.md](SCREENSHOTS.md) and [SCREENSHOTS.html](SCREENSHOTS.html).
- To use one in Claude, add the skill folder (or just its `SKILL.md`) to your skills.
